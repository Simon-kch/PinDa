## 项目在哪

本仓库根目录（与本文件同级，`index.html` 所在处）

单页应用 + 一个 Node 服务（发验证码邮件），无第三方依赖：

```
index.html                 页面入口
assets/styles.css          全部样式（品牌变量在顶部，星图主题在末尾）
assets/js/*.js             数据、视图、路由、星图、发信等
assets/data/sky.json       真实星表（2950 颗恒星 + 12 星座连线）
server.js                  静态服务 + 邮箱验证码接口
mailer.js                  SMTP 发信（QQ 邮箱已配好）
config.json                SMTP 凭据（不要外传、不要提交到 git）
启动本地预览.cmd           日常启动
共享给他人.cmd             临时公网隧道（localhost.run）
配置邮箱.cmd / 配置邮箱.js  换发件邮箱时用
```

## 怎么启动

双击 `启动本地预览.cmd`，或在项目根目录执行 `node server.js`。

启动后可用地址：

- 本机：`http://pinda.localhost:5173/`
- 同一 Wi-Fi 的其它设备：`http://<本机局域网IP>:5173/`（启动窗口会打印，IP 换网络会变）
- 公网临时分享：双击 `共享给他人.cmd`，会打印 `https://xxx.lhr.life`，窗口关掉即失效

## 当前配置

- 发件邮箱已配好（QQ 邮箱 SMTP），验证码会真实发到校园邮箱（`*.edu.cn` / `*.edu`）
- 服务监听 `0.0.0.0:5173`（局域网可用），只收校园邮箱
- 限流：每 IP 每小时 30 次、每邮箱每天 10 次、全站每天 300 封、60 秒重发冷却
- 运营阶段当前是「第二阶段 · 收入验证」

## 待办 / 可继续做的

- 用户和订单仍是浏览器本地存储，多设备之间数据不互通（要互通需把用户/订单搬到后端）
- 正式部署（Render / Railway / 自有服务器）后可拿带 pinda 的域名；注意验证码存在服务端内存，需单实例常驻
- 商家与校园组织合作（社团团购、活动报名）还没做
- 星图观感（密度、金色亮度、转速）可按需微调，参数在 `assets/js/skymap.js` 顶部 `DEFAULTS`

## 注意

- `config.json` 里是邮箱授权码，别发给别人；它已被服务端禁止下载（403）
- 换网络后局域网 IP 会变，看启动窗口打印的新地址
- 公网隧道是临时链接，窗口关掉就断开
